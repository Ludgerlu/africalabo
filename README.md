# AFRICA-LABO

## Description

**AFRICA-LABO** is a modern, responsive web showcase for AFRICA-LABO SARL, a company based in Douala, Cameroon. The website presents the company's expertise, product catalog, sectors of activity, customer testimonials, and contact information. It is built as a single-page Angular application and uses AOS animations and Bootstrap for a polished, accessible presentation.

The platform makes it easier for companies and institutions to discover available solutions in packaging, labeling, laboratory consumables, measurement equipment, cold-chain equipment, and other technical products.

## Project objective

The main objective of this project is to provide AFRICA-LABO SARL with a professional digital presence that:

- Presents the company's services and product range clearly.
- Improves visibility for industrial, pharmaceutical, laboratory, and healthcare clients.
- Helps prospective customers quickly identify suitable solutions and sectors of activity.
- Provides clear contact options, including telephone and WhatsApp.
- Strengthens the company's image and credibility with a modern, responsive interface.

## Main features

- Responsive navigation and mobile-friendly layout
- Company presentation and key statistics
- Product catalog organized by categories
- Sector-specific solutions
- Customer testimonials
- Direct phone, email, website, address, and WhatsApp contact options
- Scroll animations powered by AOS
- Bootstrap styling and Angular standalone components

## Technologies

- Angular 22
- TypeScript
- Bootstrap 5
- AOS (Animate On Scroll)
- RxJS

## Requirements

- Node.js
- npm
- Angular CLI 22 or compatible npm scripts

## Installation

```bash
npm install
```

## Development server

```bash
npm start
```

Open `http://localhost:4200/` in a browser. The application reloads automatically when source files are changed.

## Build

```bash
npm run build
```

The production files are generated in the configured Angular build output directory.

## Tests

```bash
npm test
```
